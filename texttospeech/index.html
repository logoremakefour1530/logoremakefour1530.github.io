Text-to-Speech Demo — Multi-language & Brand-style Presets

Legal / usage note: This demo uses the browser's speech synthesis voices. "Brand" and character voices are simulated presets (pitch/rate/voice heuristics) only — they are NOT the actual copyrighted or proprietary voices. Do not use this to impersonate people or copyrighted characters.
Integration notes (for cloud TTS)

If you have Google Cloud TTS or Microsoft Azure keys, you can integrate server-side and return audio to the browser. See commented examples in script.js.
